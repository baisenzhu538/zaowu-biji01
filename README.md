# 造物笔记 · Builder's Notes

> 一堂 Vibe Coder 的 AI 编程武器库
> Builder's Notes — The Vibe Coding Arsenal

---

## 这是什么

一个给一堂同学的 **VibeCoding 名词站和武器库**。

新人学 Vibe Coding 最大的问题，是各种技术概念和名词卡住，产生恐慌和焦虑。所以做一个网站，包含高频常用名词解析、常用的 VibeCoding 口喷提示词话术，以及常用 UX 名词和风格。

**一句话理念**：Vibe 是你的"想象力"，Coding 得懂点"专业基本功"。

---

## 三个模块

| 模块 | 定位 | 内容 |
|---|---|---|
| **名词解码** | 查名词 | Top 50 名词，每词一页 |
| **实战锦囊** | 拿小抄 | 做好看 / 不怕错 / 稳定做 三份小抄 |
| **陪练对话** | 找 Agent | 教学 Agent + 技术 Agent |
