> 编制依据：`90.需求：MVP最小需求清单.md`、`92.技术：技术栈方案.md`、`93.交互：前端交互框架.md`、`94.风格：视觉风格方案.md`

## ★ 使用说明（给人看，不发给 AI）

1. 把本文档 **从「一、任务」到「十、禁止事项」** 整段复制，作为提示词发给 AI。
2. 第十一章（验收清单）**保留也在提示词里** —— 让 AI 自己先对照自查一遍，能显著提高一次通过率。
3. 如果 AI 一次做不完四个页面，就**按页拆开发**：第一章的任务描述 + 对应页面的章节单独发。
4. 本次范围**严格限定为前端 + 假数据**。提示词里已明确禁止接后端、禁止扩展功能，不要临时加需求。

## 一、任务

你是资深前端工程师。请为「造物笔记」网站生成**完整可运行的前端代码**，包含四个核心页面：

1. **首页**
2. **笔记详情页**（含两种形态：名词详情页、Wiki 长页）
3. **搜索/筛选页**（含搜索、分类筛选、目录浏览三种模式）
4. **陪练页**

### 硬性边界（必须遵守，违反即不合格）

| # | 约束 | 说明 |
|---|---|---|
| 1 | **只做前端** | 不写后端代码、不建服务端目录、不配数据库 |
| 2 | **只用假数据** | 所有数据来自本地 JSON / JS 常量文件，**不发起任何网络请求** |
| 3 | **不接后端** | `fetch` / `axios` / `XMLHttpRequest` **一律禁止使用** |
| 4 | **不扩展功能** | 只实现本提示词写明的功能。**不要**自作主张加登录、收藏、评论、暗色模式、多语言、埋点等 |
| 5 | **不引入 UI 组件库** | 不用 Tailwind / shadcn / Ant Design / Element 等。用**原生 CSS + CSS 变量** |

> 若某个功能在本提示词中未提及，**默认不做**。宁可少做，不可多做。

### 技术栈（固定，不要替换）

| 项 | 选型 |
|---|---|
| 构建 | **Vite + Vue 3**（组合式 API，`<script setup>`） |
| 路由 | **vue-router 4** |
| 样式 | **原生 CSS + CSS 变量**（`design-tokens.css` + 组件内 `<style scoped>`） |
| 数据 | **本地 JSON 文件**（放在 `src/data/`） |
| 搜索 | **纯前端字符串匹配**（大小写不敏感） |
| 字体 | Manrope Variable（用系统字体兜底） |

> 说明：原技术方案是 VitePress，但本次要生成的是**四个自定义交互页面**（首页卡片、对话界面等），
> VitePress 的文档站抽象层反而碍事，故本次用 Vite + Vue 3 直接实现。
> 产出应为标准 Vite 项目，`npm install && npm run dev` 即可运行。

## 二、项目背景（帮助理解内容，不要输出到界面）

- **造物笔记** —— 一堂 Vibe Coder 的 AI 编程武器库
- **服务对象**：VibeCoding 新人小白，他们最大的痛点是「被技术名词卡住 → 恐慌焦虑」
- **一句话理念**："Vibe 是你的'想象力'，Coding 得懂点'专业基本功'。"
- **三大模块**：名词解码（查名词）/ 实战锦囊（拿小抄）/ 陪练对话（找 Agent）
- **核心设计决策**：名词解码与武器库走**两套完全不同**的内容呈现模式
  - 名词解码 = 50+ 个独立页，碎片查阅，目标是「3 秒查到」
  - 武器库 = 3 个 Wiki 长页，一页到底，目标是「系统学习」

在 `src/data/` 下建立以下文件。**内容必须是真的假数据 —— 结构完整、条数够用、中文通顺，不要写 `xxx` / `TODO` / 空数组。**

**3 篇**：`make-it-pretty`（做好看）/ `debug-it`（不怕错）/ `ship-it`（稳定做）。

      {
        id: 'intro',

export const mockReplies = {

## 六、页面二：笔记详情页

⚠️ **本页有两种形态，是两个不同的路由，必须分别实现。**

### 6.A 形态一：名词详情页 —— 路由 `/term/:id`

#### 结构（自上而下）

```
面包屑：首页 / 名词解码 / {分类名} / {名词名}
标题区
├─ 色标标签（🟠 必知必会 / 🟢 口语化 / 🔵 专业）
└─ 中文名 + 英文名
一句话解读（突出，字号 20-22px，左竖线强调）
大白话解读（浅色背景区块）
专业理解（默认折叠，按钮「展开专业解释 ↓」）
Vibe 常用话术（3 条，每条一张浅蓝卡片 + 复制按钮）
相关推荐（3-5 张名词卡片；若为空则整块隐藏）
底部：上一词 / 下一词
```

#### 交互

| 操作 | 行为 |
|---|---|
| 点「展开专业解释」 | **就地展开**（不跳页不弹窗），按钮文案变「收起 ↑」 |
| 点话术复制按钮 | 文本进剪贴板 → 按钮变「✓ 已复制」→ **2 秒后**恢复 |
| 点相关推荐卡 | 跳转对应 `/term/:id`，**滚动位置重置到顶** |
| 点上一词/下一词 | 跳转到**同分类内**相邻词，滚动到顶 |
| 点面包屑分类名 | 跳 `/browse?category={id}` |

> 复制功能用 `navigator.clipboard.writeText()`，并 **catch 失败**：失败时提示「复制失败，请手动选择」。

#### 核心体验指标

**「3 秒查到」**：从进入本页到看清「一句话解读」，中间**不允许有任何需要点击才能看到的内容**。
即 —— 一句话解读、大白话**必须默认可见**，只有「专业理解」可以折叠。

#### 状态

| 状态 | 表现 |
|---|---|
| 加载中 | 骨架屏：标题块 + 一句话块 + 3 个话术卡块 |
| `id` 不存在 | 页面显示「这个词还没收录」+ 搜索框 + 「看看相近的词」（3 个推荐） |
| 话术缺失 | 话术区显示「话术补充中」，**其他区块正常显示** |
| 相关推荐为 0 | **整块隐藏**，不留空白框 |
| 上一词/下一词不存在 | 对应按钮置灰不可点 |

### 6.B 形态二：Wiki 长页 —— 路由 `/wiki/:id`

#### 结构（桌面端两栏）

```
┌──────────────────────────────────────────────┐
│ 顶部导航栏                                     │
├────────────┬─────────────────────────────────┤
│ 侧边栏 200px│ 内容区 680px（居中偏左）          │
│            │                                 │

│            │                                 │
│            │  右下角：回到顶部浮动按钮           │
└────────────┴─────────────────────────────────┘
```

#### 必须实现的三个交互

1. **TOC 点击 → 平滑滚动**到对应章节（`scrollIntoView({ behavior:'smooth' })`）
2. **滚动时 TOC 当前章节自动高亮**（`IntersectionObserver`）
3. **内容不做折叠** —— Wiki 是用来通读的，**禁止加任何「展开更多」**

#### 样式要求

| 项 | 值 |
|---|---|
| 侧边栏宽度 | `--sidebar-width` 200px，`position: sticky; top: 导航高度` |

| 章节标题 | `--font-sans`，`font-weight: 650`，22-28px |

| 话术区 | **与名词详情页样式完全一致**（浅蓝卡 + 复制按钮） |
| 回到顶部 | 右下角固定浮动按钮，滚动超过一屏才出现 |

#### 状态

| 状态 | 表现 |
|---|---|
| 加载中 | 侧边栏 TOC 骨架（几行灰条）+ 正文骨架 |
| 内容为空 / `ready:false` | 「这份小抄还在整理中」+ 返回首页按钮 |

| `id` 不存在 | 「没找到这份小抄」+ 返回首页 |

## 七、页面三：搜索/筛选页 —— 路由 `/search` 与 `/browse`

本页承担**三种模式**，通过路由和 query 区分：

| 模式 | 触发 | URL |
|---|---|---|
| 搜索模式 | 首页搜索框 | `/search?q={关键词}` |
| 分类筛选模式 | 首页「准确聊」卡 | `/browse?category={id}` |
| 目录浏览模式 | 首页「浏览全部」 | `/browse` |

### 7.1 搜索模式 `/search`

**结构**：
```
顶部导航栏
搜索框（已填关键词，可编辑，带清空按钮）
结果计数：「找到 12 个相关名词」
结果列表（卡片流，每张含：色标标签 + 中英文名 + 一句话解读 + 匹配片段高亮）
（若结果 > 20）「加载更多」按钮
```

**交互**：

| 操作 | 行为 |
|---|---|
| 输入关键词 | **实时联想**，**输入停顿 300ms 后**触发（防抖），下方显示匹配名词 |
| 回车 / 点搜索 | 更新结果为完整列表 |
| 点结果卡 | 跳 `/term/:id` |
| 点清空按钮 | 清空输入 → 回 `/browse` |
| 点「加载更多」 | 每次追加 20 条 |

**搜索匹配范围**（四个字段都匹配，大小写不敏感）：
`name` / `nameEn` / `oneLine` / `plain` / `phrases[]`

**匹配高亮**：命中的关键词用 `<mark>` 包裹，背景 `--color-accent-weak`。

### 7.2 分类筛选模式 `/browse?category={id}`

**结构**：
```
顶部导航栏
页面标题：准确聊 · 按分类查名词
分类卡片网格（每张：图标 + 分类名 + 词条数）
  └─ 若选了分类：先是分类选择条，下面是该分类的词列表
```

**交互**：

| 操作 | 行为 |
|---|---|
| 点分类卡 | **就地切换**为筛选模式（不跳页），更新 URL query |
| 点词条卡 | 跳 `/term/:id` |

### 7.3 目录浏览模式 `/browse`

两个目录分区：
- **名词解码**：九大分类卡片网格
- **实战锦囊**：**三张策略大卡片**（做好看 / 不怕错 / 稳定做），点击**直达**对应 Wiki

### 7.4 响应式

| 断点 | 分类网格 | 结果列表 |
|---|---|---|
| ≥1024px | 3 列 | 单列，卡片横向排布 |
| 768-1023px | 2 列 | 单列 |
| <768px | 1 列 | 单列，卡片纵向堆叠 |

### 7.5 状态

| 状态 | 表现 |
|---|---|
| 搜索中 | 结果区显示「搜索中…」+ 转圈；**不清空已有结果** |
| **无结果** | 空状态插图（内联 SVG）+ **「没找到「{关键词}」」** + 引导文案 + 推荐 3 个热门名词 |
| 搜索框为空提交 | 不提交，提示「请输入关键词」 |
| 输入特殊字符 | **正常处理**（转义），不报错 |
| 分类无词条 | 「这个分类还在建设中」+ 返回分类列表按钮 |
| 结果过多 | 分页或「加载更多」，**不一次全渲染** |

> **禁止**：无结果时只显示「暂无数据」四个字。空状态必须回答「我现在该做什么」。

## 八、页面四：陪练页 —— 路由 `/coach`

> ⚠️ **需求缺口**：两个 Agent 的具体能力在其他文档中无定义。
> 本页**只实现交互骨架 + 本地假回复**，不要设计复杂的对话逻辑。

### 8.1 结构

**状态一：选择 Agent**
```
顶部导航栏
页面标题：陪练对话
Agent 选择区（2 张卡片）
├─ 教学 Agent · 技术名词解读 Partner
└─ 技术 Agent · 技术配置专家 Partner
```

**状态二：对话中**
```
顶部：当前 Agent 名称 + 切换入口 + 清空对话
对话区（消息气泡流）
├─ 用户消息：右对齐
└─ Agent 消息：左对齐，带头像
底部：输入框 + 发送按钮
```

### 8.2 交互

| 操作 | 行为 |
|---|---|
| 点 Agent 卡 | 进入对话界面，显示该 Agent 的**欢迎语** + **3 个推荐提问**（可点击直接发送） |
| 发送消息 | 用户气泡**即时上屏** → Agent 回复**打字机逐字显示** |
| 点推荐提问 | 等同发送该问题 |
| 切换 Agent | 提示「切换后对话上下文将重置」，确认后切换 |
| 清空对话 | **二次确认**后清空 |
| 输入为空 | 发送按钮**禁用**（`disabled`） |

### 8.3 流式输出（用打字机效果模拟）

**必须实现「停止生成」按钮**，且要正确处理三种情况：

| 情况 | 处理 |
|---|---|
| 正常输出完 | 隐藏「停止」按钮，消息标记为完成态 |
| 用户中途取消 | **停止生成，保留已输出内容**（不清空） |
| 组件卸载 / 路由离开 | **清除定时器**，避免内存泄漏 |

> 打字速度建议：**每字 30-50ms**。用 `setTimeout` 递归或 `setInterval`，并在 `onUnmounted` 里清理。

### 8.4 状态

| 状态 | 表现 |
|---|---|
| 等待回复 | 打字机逐字显示 + 「思考中」提示 |
| 对话为空 | 显示 Agent 欢迎语 + 3 个推荐提问 |
| 输入为空 | 发送按钮禁用 |
| 匹配不到关键词 | 回复兜底文案（如「这个问题我还没学会，换个说法试试？」） |
| Agent 不可用 | 卡片置灰 + 「即将上线」 |

### 8.5 明确不做

- ❌ 不接 LLM、不发网络请求
- ❌ 不做登录 / 额度控制
- ❌ 不做多轮上下文记忆（每次回复都是独立匹配）
- ❌ 不做引用来源、不做对话导出
