## 二、三大模块与页面清单

### 2.1 三模块命名 `[01.命名]`

| 模块 | 命名 | 定位 | 内容形态 |
|---|---|---|---|
| 名词篇 | **名词解码** | 查名词 | 每词一页（50+ 个独立页） |
| 武器篇 | **实战锦囊** | 拿小抄 | 3 个 Wiki 长页 |
| 陪练篇 | **陪练对话** | 找 Agent | `[缺口]` 无详细设计 |

### 2.2 页面类型与数量 `[22.架构]`

| 页面类型 | 数量 | 用途 |
|---|---|---|
| 首页 | 1 | 四维能力装备卡 + 搜索 |
| 准确聊装备页 | 1 | 按分类浏览 50 个名词（**唯一保留的中间导航页**） |
| 名词内容页 | 50+ | 每词一页：解读 + 大白话 + 话术 |
| 目录浏览页 | 3 | 名词解码 / 实战锦囊 / 陪练对话 |
| Wiki 长页面 | 3 | 做好看 / 不怕错 / 稳定做（侧边栏 TOC + 连续滚动） |

### 2.3 首页结构 `[22.架构]`

- 全局顶部导航：**Logo + 三模块 tab + 搜索**
- 搜索框
- 四维能力装备卡：

| 装备卡 | 去向 |
|---|---|
| 📖 准确聊 | → 按分类选名词的**中间页** |
| 🎨 做好看 | → 做好看 Wiki 长页 |
| 🐛 不怕错 | → 不怕错 Wiki 长页 |
| 💾 稳定做 | → 稳定做 Wiki 长页 |

- "浏览全部"入口 → 模块目录（名词 / 锦囊）

### 2.4 核心设计决策 `[22.架构]`

> "名词解码和武器库走两套完全不同的内容呈现模式。"

| 对比 | 名词解码 | 武器库（做好看/不怕错/稳定做） |
|---|---|---|
| 用户行为 | "卡住了，查一个词" | "想系统提升这种能力" |
| 内容关系 | 词与词之间松散关联 | 策略之间是完整方法论 |
| 最佳体验 | 每词一页，3 秒查到 | 一页到底，信息密度高 |
| 导航方式 | 搜索 + 分类卡片 | 侧边栏 TOC + 连续滚动 |
| 页面数 | 50+ 个独立页 | 3 个 Wiki 长页 |

## 三、名词库需求

### 3.1 词条规模与来源 `[11.清单]`

| 项 | 内容 |
|---|---|
| 词条总数 | 50 个 |
| 主来源 | `VibeCoding-开发基础名词解释手册.docx`（45 个名词） |
| 补充来源 | `vibehub-source-docs-20260729-7b390283426a.zip` 的 `beginner-copy/*.json`，补入 5 词：域名、DNS、HTTP、HTTPS、npm |
| 明确排除 | 视频索引、商业调研、Agent CLI 需求等资料未混入 |
| 暂未纳入 | 技术栈 / Tech Stack、GraphRAG / Graph RAG（留作"进阶词库"） |

### 3.2 每词字段 `[00.顶层 + 11.清单]`

| 字段 | 说明 |
|---|---|
| 名词 | 中文名 + 英文名（如"前端与后端 / Frontend & Backend"） |
| 一句话解读 | 上层字段，为检索补充 |
| 大白话解读 | 口语化解释 |
| 专业理解 | 保留或压缩自源资料 |
| Vibe 常用话术 | **每词 3 条**，从简单到复杂 |

**话术的 3 条分别对应** `[11.清单]`：前期设计 / 中期沟通 / 后期调试，面向"口喷"使用，可直接拿来说。

### 3.3 名词内容页结构 `[22.架构]`

> 色标 + 名词 + 一句话解读 + 大白话 + 专业理解（**折叠**）+ 3 条话术 + 相关推荐

### 3.4 分类体系 `[存疑 · 需裁决]`

文档中存在**两套并存的分类方案**：

| 方案 | 来源 | 结构 |
|---|---|---|
| A. 九大分类 | 11.清单 / 22.架构（"展示九大名词分类卡片"） | 一、网页与程序基础；二、编程语言、文档与数据；三、开发工具与运行环境；四、版本管理；五、网络与用户状态；六、数据库、性能与设计；七、测试与调试；八、部署与运维；九、前沿技术与产品体验 |
| B. 4 层金字塔 | 12.D版（文件名标 √） | 第一章 Web 是什么（15 词）；第二章 怎么写代码（14 词）；第三章 怎么搭系统（8 词）；第四章 怎么交付和维护（13 词） |

- A 方案的问题（12.D版 原文指出）："分类太多、大小不均（有的分类只有 2 个词）、边界模糊、缺乏递进主线"
- B 方案的递进主线：**看懂网页 → 学会写代码 → 搭出系统 → 交付上线**
- 22.架构 页面设计中写的是"**九大**名词分类卡片"，与 A 方案对应

**需明确的点**：名词内容页与装备页采用哪一套分类。
