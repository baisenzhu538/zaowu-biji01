# 造物笔记 · 页面交互架构

> 四维能力装备卡做首页核心入口。名词解码走每词一页，三个武器库（做好看/不怕错/稳定做）各为一个 Wiki 长页，高信息密度连续滚动。
>
> 输入来源：00 理念 / 01 命名 / 02 创意 / 11 名词清单 / 12 调试策略 / 13 UX 指南 / 14 版本管理 / 21 场景设计。

---

## 一、架构全景图

```
                        首页
                 （四维能力装备卡）
                         │
          ┌──────────────┼──────────────┐
          ▼              ▼              ▼
     📖 准确聊          🎨🐛💾         "浏览全部"
    按分类选名词     做好看/不怕错         │
          │          /稳定做              │
          ▼         直接进 Wiki 长页       ▼
   ┌───────────┐         │        ┌──────────┐
   │名词内容页  │         │        │ 模块目录  │
   │（50个独立）│         │        │名词/锦囊  │
   └───────────┘         │        └────┬─────┘
                         │             │
                         ▼             ▼
                  ┌────────────────────────────┐
                  │    Wiki 长页面（3个）        │
                  │ 做好看 / 不怕错 / 稳定做      │
                  │ 侧边栏 TOC + 全量内容连续滚动 │
                  └────────────────────────────┘
```

**核心设计决策**：名词解码和武器库走两套完全不同的内容呈现模式。

| 对比   | 名词解码       | 武器库（做好看/不怕错/稳定做） |
| ---- | ---------- | ---------------- |
| 用户行为 | "卡住了，查一个词" | "想系统提升这种能力"      |
| 内容关系 | 词与词之间松散关联  | 策略之间是完整方法论       |
| 最佳体验 | 每词一页，3秒查到  | 一页到底，信息密度高       |
| 导航方式 | 搜索 + 分类卡片  | 侧边栏 TOC + 连续滚动   |
| 页面数  | 50+ 个独立页   | 3 个 Wiki 长页      |

## 二、页面类型

| 页面类型 | 数量 | 用途 |
|---------|------|------|
| **首页** | 1 | 四维能力装备卡 + 搜索 |
| **准确聊装备页** | 1 | 按分类浏览 50 个名词（唯一保留中间导航页的维度） |
| **名词内容页** | 50+ | 每词一页：解读 + 大白话 + 话术 |
| **目录浏览页** | 3 | 名词解码 / 实战锦囊 / 陪练对话 |
| **Wiki 长页面** | 3 | 做好看 / 不怕错 / 稳定做。含侧边栏 TOC，全量内容连续滚动 |

## 三、首页

与上一版保持不变：搜索框 + 四维能力装备卡 + 三个模块入口。四个装备卡中，"📖 准确聊"跳转到按分类选名词的中间页；"🎨 做好看""🐛 不怕错""💾 稳定做"直接跳转到对应 Wiki 长页。

---

## 四、准确聊装备页（唯一保留的中间导航）

用户点击"📖 准确聊"后进入此页。展示九大名词分类卡片，用户选择后进入对应的名词内容页。结构和交互与上一版相同。

### 5.2 侧边栏 TOC

- 固定在左侧（桌面端），移动端折叠为顶部下拉
- 当前阅读到的章节高亮（IntersectionObserver）
- 点击任意章节标题平滑滚动到对应位置
- TOC 结构映射源文档的主要章节标题

### 5.3 内容组织

每张 Wiki 页面按源文档的结构线性展开，不做折叠隐藏。所有策略、话术、表格都在一个页面内，用户滚动即可阅读全部内容。

**做好看 Wiki（基于 13 文档）**：

4. 诊断篇：UX 四层诊断法

### 5.4 设计要点

- **侧边栏宽度**：桌面端 200px，移动端折叠
- **内容区最大宽度**：680px，居中偏左
- **章节标题**：用 Manrope Variable 字体，wght 650-720，字号 22-28px
- **话术区**：和名词内容页一致，浅蓝背景卡片 + 复制按钮
- **策略梯度标识**：🟢🟡🟠🔴 四色标签
- **信息密度**：不做折叠。Wiki 页面就是用来通读的，不是用来"展开"的
- **回到顶部**：右下角固定浮动按钮

## 六、名词内容页

与上一版相同：全局顶部导航（Logo + 三模块 tab + 搜索）。
